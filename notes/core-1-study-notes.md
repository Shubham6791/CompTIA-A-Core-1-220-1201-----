# CompTIA A+ Core 1 (220-1201) — Study Notes

## 1. Mobile Devices

### Laptop Components
- **Display:** Shows visual output.
- **Battery:** Supplies portable power.
- **Keyboard and touchpad:** Input devices.
- **Wi-Fi adapter:** Provides wireless network connectivity.
- **Webcam and microphone:** Support video and audio communication.

### Mobile Connectivity
- **Wi-Fi:** Wireless local area network connectivity.
- **Bluetooth:** Short-range connections to peripherals.
- **NFC:** Very short-range communication, commonly used for contactless interactions.
- **Cellular:** Mobile network connectivity through a carrier.

## 2. Networking

### Network Types
- **LAN:** Network covering a limited area, such as an office.
- **WAN:** Connects networks across larger geographical areas.
- **WLAN:** A LAN using wireless networking.
- **PAN:** Personal-area connectivity between nearby devices.

### Common Ports

| Protocol | Port | Purpose |
|---|---:|---|
| FTP | 20/21 | File transfer |
| SSH | 22 | Secure remote administration |
| Telnet | 23 | Unencrypted remote terminal |
| SMTP | 25 | Email transfer |
| DNS | 53 | Name resolution |
| DHCP | 67/68 | Automatic IPv4 configuration |
| HTTP | 80 | Web traffic |
| HTTPS | 443 | Encrypted web traffic |
| RDP | 3389 | Remote Desktop |

### Network Troubleshooting Commands
- `ipconfig` — Displays Windows IP configuration.
- `ping` — Tests IP reachability.
- `tracert` — Shows the route toward a destination.
- `nslookup` — Queries DNS.
- `netstat` — Displays network connections and statistics.

## 3. Computer Hardware

### CPU
The Central Processing Unit executes instructions and processes data.

### RAM
Random Access Memory temporarily stores data and instructions used by running programs. It is volatile memory.

### Storage
- **HDD:** Uses magnetic disks and moving parts.
- **SSD:** Uses flash memory and has no moving mechanical parts.
- **NVMe:** A storage protocol commonly used with PCIe-connected SSDs.
- **SATA:** An interface used by storage devices.

### Motherboard
The main circuit board connecting the CPU, memory, storage, expansion cards, and peripherals.

### Power Supply
Converts AC power from the wall into DC power used by computer components.

### Cooling
Fans and heatsinks help remove heat. Poor cooling can cause overheating and performance throttling.

## 4. Virtualization and Cloud Computing

### Virtualization
Virtualization allows multiple virtual machines to run on a physical computer using a hypervisor.

- **Type 1 hypervisor:** Runs directly on the host hardware.
- **Type 2 hypervisor:** Runs on top of a host operating system.

### Cloud Service Models
- **IaaS:** Infrastructure as a Service.
- **PaaS:** Platform as a Service.
- **SaaS:** Software as a Service.

## 5. Hardware and Network Troubleshooting

### Troubleshooting Method
1. Identify the problem.
2. Establish a theory of probable cause.
3. Test the theory.
4. Create a plan and implement the solution.
5. Verify full system functionality.
6. Document findings, actions, and outcomes.

### Example: No Network Connectivity
1. Check the cable or Wi-Fi connection.
2. Run `ipconfig` to inspect the IP address.
3. Check the default gateway.
4. Ping the local gateway.
5. Use `nslookup` to test DNS resolution.
6. Record the results and confirm connectivity.
